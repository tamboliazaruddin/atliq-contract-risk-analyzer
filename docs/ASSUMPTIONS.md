# MVP assumptions (stated explicitly, per client guidance)

Sources: [M1] Client Meeting 1 (7 Oct 2026), [M2] Client Meeting 2 (10 Oct 2026), [DS] dataset.

1. Primary user is Karandeep; Bhavin, Dhaval and Jay are delegated first/second reviewers [M1, M2]. Clients and partners are not users.
2. In scope: client and partner contracts, including NDAs and companion documents (BAA, DPA). Freelancer and employee contracts are out of scope [M1, M2].
3. Lifecycle: Received → In review → Negotiating → Signed / Rejected. Status changes are always human actions.
4. Inputs: PDF/DOCX/MD text. Dataset files are Markdown extracted from PDFs [M2: converter is a value add].
5. Side-channel commitments (calls, WhatsApp) are captured as a short "deal context note" typed by the reviewer at intake, not synced live [M1].
6. No fixed negotiation policy exists [M1]; the tool shows precedent, never auto-thresholds commercial terms. Deterministic checks only for facts (entity, law, required documents, dates).
7. Over-flagging is acceptable; misses are the expensive failure [M2]. Uncertain items are labelled "Not sure — please verify" [M2].
8. Expired restrictions remain visible, labelled Expired [M2].
9. A negotiated version is always re-reviewed in full [M2].
10. English only; web portal only; no login for the demo [M1, M2].
11. Baselines: ~2 h standard review, 6–8 h complex; 1 week–1 month turnaround; ~3–4 contracts + 4–5 NDAs per month [M2]. Target: complete brief in < 5 minutes [M1].
12. "Today" for the dataset = 2026-09-28 [DS].
13. Model APIs are acceptable; minimise exposure by masking names/rates before calls [M1].
